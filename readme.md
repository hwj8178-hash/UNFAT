# UNFAT — 역사학 연구 비서 (CLIO PROTOCOL)

역사학 연구에 특화된 멀티 AI 비서입니다.
Gemini(음성·제어) + Claude(분석) 를 함께 운용하며, 한글·PDF·이미지 사료를 분석합니다.

---

## 주요 기능

### 기본 기능
| 기능 | 설명 |
|---|---|
| 음성 인식 | 실시간 한국어 음성 대화 |
| 컴퓨터 제어 | 앱 실행, 파일 관리, 터미널 명령 |
| 화면 인식 | 화면·웹캠 이미지 분석 |
| 화자 인증 | 등록된 목소리에만 반응하는 웨이크워드 |
| 손 제스처 제어 | 손 동작으로 볼륨·마우스 제어 |

### 역사학 연구 특화 기능

| 기능 | 음성 명령 예시 |
|---|---|
| 논문·사료 분석 | "이 PDF 논문 분석해줘" |
| NARA 자료 | "RG 59, 엔트리 1234 자료야" → 아카이브 식별자 자동 저장 |
| 국사편찬위원회 | AUS* 파일명 자동 인식 → 사료참조번호 추출 |
| 한자 인식 | 한글·한자 병용 자료 자동 독음 변환 |
| 각주 생성 | "23페이지 식민지 관련 각주 만들어줘" |
| 연구사 공백 | "지금까지 정리된 연구에서 공백 찾아줘" |
| 학술 작문 | "이 주제로 서론 써줘" — 학습된 논문 문체 참조 |
| 옵시디안 연동 | 분석 결과 자동 저장 |

### 지원 파일 형식

| 형식 | 처리 방법 | 각주 정확도 |
|---|---|---|
| PDF | pdfplumber (페이지별 추출) | 높음 |
| HWP/한글 | hwp5txt 또는 LibreOffice 변환 | 중간 (페이지 추정) |
| DOCX/Word | python-docx | 중간 (페이지 추정) |
| JPG/PNG | EasyOCR (한국어·영어·한자) | 중간 (OCR 품질 의존) |

### 옵시디안 연동 구조

```
옵시디안볼트/
└── 역사학연구/
    ├── 미국자료/
    │   ├── RG_59/             ← NARA 자료 (RG별)
    │   └── 국편사료/          ← 국사편찬위원회 AUS 자료
    ├── 논문분석/              ← 한국어 학술 논문
    ├── 개념인덱스/
    ├── 저자인덱스/
    └── 연구사분석.md
```

## 설치

```bash
# 권장 (Python 3.11 ~ 3.14 자동 처리)
bash install.sh

# 수동
pip install -r requirements.txt
pip install -r requirements-optional.txt  # 선택 기능 (GUI 자동화, 화자 인증)
playwright install
python main.py
```

### 요구사항

| 항목 | 내용 |
|---|---|
| OS | Windows 10/11, macOS, Linux |
| Python | 3.11 이상 (3.14 지원) |
| 마이크 | 음성 대화 필수 |
| API 키 | Gemini API 키 + Claude API 키 |

### API 키 설정

`config/api_keys.json` 파일 생성:

```json
{
  "gemini_api_key": "YOUR_GEMINI_KEY",
  "claude_api_key": "YOUR_CLAUDE_KEY"
}
```

## AI 역할 분담

| AI | 역할 |
|---|---|
| Gemini | 음성 인식, 명령 이해, 컴퓨터 제어, 최종 응답 출력 |
| Claude | 논문 심층 분석, 각주 추출, 연구사 공백 도출, 학술 작문 |
